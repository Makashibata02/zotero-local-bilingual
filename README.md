# Local Bilingual PDF · 本地双语 PDF

[English](README.en.md) · [下载 1.0](https://github.com/Makashibata02/zotero-local-bilingual/releases/tag/v1.0.0) · [使用手册](docs/使用手册.md)

在 Zotero 中翻译论文和讲义 PDF，保留原文页面、图片与数学对象，生成便于对照阅读的双语 PDF 或独立译文 PDF。可以使用免 Key 的免费翻译服务，也可以配置自己的大模型 API。

运行环境：**Windows 10/11 x64**。安装包声明支持 Zotero 7–10；其他操作系统暂不支持自动引擎安装。

## 功能

- **左右整页对照**：左侧完整原文页，右侧对应译文页，尽量保留原版式、图表和公式。
- **免费或自带 Key**：提供实验性的 Bing、腾讯交互翻译，以及 DeepSeek 和自定义 OpenAI 兼容 API；支持多套命名模型配置。
- **七种目标语言**：简体中文默认，另有繁体中文、日语、韩语、法语、德语和西班牙语。
- **三种输出**：双语、译文、双语＆译文；两份产物共用一次翻译结果。
- **多篇任务队列**：默认串行，可主动开启最多两篇并行，免费任务最多一篇运行。
- **可管理的工作台**：显示论文标题、附件、阶段、进度和用量，支持取消、恢复、打开结果、搜索及历史隐藏／恢复。
- **额度保护**：记录累计用量，达到上限后暂停，由用户确认追加额度再继续。
- **自动准备环境**：顶部选择在线安装或离线 ZIP，无需自行安装 Python、uv、BabelDOC 或运行终端。

## 安装与开始翻译

1. 从 [Release](https://github.com/Makashibata02/zotero-local-bilingual/releases/tag/v1.0.0) 下载 `zotero-local-bilingual-1.0.0.xpi`。在 Zotero“工具 → 插件 → 从文件安装插件”中选择它，然后重启 Zotero。
2. 打开“设置 → 本地双语 PDF”，点击顶部的**在线下载并安装**。插件会直接从本项目 GitHub Release 下载匹配引擎、校验并安装，无需手动下载 ZIP 或配置 GitHub Token。
3. 选择免费服务，或填写自己的 API 地址、模型名称和 Key，点击**保存并测试**，按按钮下方的提示完成配置。
4. 选中 PDF 或文献条目，右键选择**翻译 PDF…**，确认文件、服务、目标语言、输出方式和排队设置，点击**确认并入队**。

![引擎安装界面示意](docs/images/settings-100.png)

引擎下载约 **415 MB**，安装后约 **884 MB**。在线安装支持进度显示、断点续传和 SHA-256 校验。**备用离线安装**：GitHub 下载受限时，从同一 Release 取得 `zlb-engine-1.0.0-windows-x64.zip`，在设置顶部选择“离线导入”。离线导入指安装环境的方式，翻译仍需连接所选服务。

安装引擎不调用翻译服务。首次配置会用一页 PDF 检查完整流程，成功后保存只检查一次服务连接；使用自己的 API 时会产生少量用量，按钮旁有说明。安装和配置的结果显示在对应按钮下方。

## 选择翻译服务

| 服务 | 配置方法 | 适合用途 |
|---|---|---|
| 免费 Bing／腾讯 | 选择服务，无需 Key | 快速阅读；网页接口为实验性，可能限流或失效 |
| DeepSeek | 选择预设，填写自己的 Key 和模型 | 使用自己的模型账户翻译 |
| 自定义兼容 API | 填写 API 地址、模型名称和 Key | 接入支持 OpenAI 兼容接口的服务 |

API 配置可以命名和保存，翻译确认窗口中按“配置名称 · 模型”选择。切换已保存配置不会自动调用模型。免费模式不使用大模型提示词或术语提示；API 模式可在高级选项中设置补充提示词、术语、页码、字体和用量上限。

## 语言与输出

目标语言默认**简体中文**，可改为繁体中文、日语、韩语、法语、德语或西班牙语。支持状态由所选服务决定，不支持的选项会禁用。

![翻译确认界面示意](docs/images/confirm-030-ui-fix-options.png)

| 输出方式 | 生成文件 |
|---|---|
| 双语（默认） | 一个左右整页对照 PDF |
| 译文 | 一个独立译文 PDF |
| 双语＆译文 | 上述两份 PDF；只翻译一次 |

选择文献条目时默认勾选主 PDF，可另外选择补充附件。页码留空为全文，可在高级选项填写 `1-3,8`。取消确认不会提交任务。

产物自动加入原文献条目，原附件保留。文件名包含作者、年份、标题、语言、输出类型和服务／模型，例如：

```text
Tachella 等 - 2025 - UNSURE_zh-CN_dual_deepseek-chat.pdf
```

`dual` 表示双语，`mono` 表示独立译文。

## 队列、进度与额度

选择多篇 PDF 后可一起入队，默认逐篇处理；开启两篇并行时，两篇 API 任务会同时消耗额度。免费任务始终最多一篇运行。

工作台自动打开，显示真实论文标题和附件名。窄窗口使用任务卡片，展开详情可查看完整信息。关闭工作台不会取消翻译。隐藏已结束的历史记录只改变列表显示，不删除文件、缓存或累计用量。

API 任务默认每篇累计上限为 **100 万 tokens／1000 次请求**；免费任务为 **100 万字符／2000 次请求**。可在高级设置降低上限。token 上限不是固定人民币预算，实际费用由服务商决定。达到上限后暂停，确认追加额度才继续；恢复任务不会清零累计消耗。

## 数据与隐私

API Key 保存在 **Windows 凭据管理器**。配置、任务、产物和缓存保存在本机 `%LOCALAPPDATA%\ZoteroLocalBilingual`，不属于源码仓库。后台服务只监听本机回环地址。

需要翻译的文本会发送给你选择的服务。免费翻译同样使用远程接口，本地引擎负责 PDF 提取、排版与任务管理。使用敏感文档前，请确认所选服务的数据政策。

## 使用边界

免费网页接口可能限流、要求验证码或变化；任务失败不会自动切换到收费 API。Google 和知网暂未接入。

参考文献、识别出的作者行和数学对象保留原文。复杂公式、图内文字、扫描 PDF 和双栏阅读顺序可能处理不完整，阅读时应对照原文；原附件批注不迁移。
