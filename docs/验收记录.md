## 安装后人工验收

1. 安装最新 XPI，重启 Zotero，核对插件和引擎均为 1.0.0。
2. 卡片选项不重叠；单篇／多篇选择正确；取消确认不创建任务。
3. 确认后自动显示工作台，标题、附件、阶段和进度可辨认。
4. 窄窗口卡片、展开详情、反馈、搜索、分页、隐藏／恢复可用。
5. 三种模式为 1／1／2 份产物，名字含语言与模型；刷新不重复导入。
6. 默认一篇，可主动选两篇；免费仍最多一篇；单项取消独立。
7. 已成功部署只测试连接；旧任务追加需确认，累计用量不清零。

尚需人工验收：全新 Windows 机器的完整线上安装、Zotero 原生设置交互、所有真实安装故障及全面学术校订。匿名地址可达性与本机浏览器检查另记，不视为干净系统安装验收。
