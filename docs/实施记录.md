# 1.0 发布记录

公开候选源码采用独立初始提交，只收录源码白名单。插件、引擎、任务与费用保护的运行逻辑保持不变，中英文 README 默认指导在线下载，离线 ZIP 作为备用。

## 发布物

XPI、引擎 ZIP、源码 ZIP、引擎清单、更新清单与 SHA256SUMS 统一为 1.0.0。引擎包含锁定依赖、模型、字体、CMap 与分词资源。源代码与运行数据分开，发布目录不进入 Git 历史。

## 隐私与分发

上传仅收录经过检查的源码白名单。模型 Key、服务令牌、配置实例、用户文献、任务数据库、日志与缓存不进入源码或发布物。Key 保存在 Windows 凭据管理器，正式应用数据不受仓库重建影响。

对源码、独立 Git 历史和实际解包的发布物运行脱敏扫描。第三方非秘密样例只按路径、行号、规则和文件哈希逐项分类，不作宽泛豁免。依赖导出使用相对路径，发布核验拒绝依赖注释中的本地绝对路径。

候选通过检查不等于已公开。新仓库创建后，必须确认它为独立仓库并检查旧问题提交 SHA 不可读取，核对 Release 资产大小与 SHA-256，再确认匿名在线下载可达。


## 1.0.1

新增模型配置删除与独立默认 API；模型和目标语言改为下拉框。服务使用配置删除标记保留历史引用，凭据删除与任务保护协同。暂停和额度受限任务可先取消，再删除配置。服务工厂不再在模块导入时初始化数据库；只有显式启动或调用工厂时初始化。匹配的离线引擎复用已核验依赖和资源，不重新下载模型。


## 1.0.2

新增托管后台的空闲安全退出与匹配版本启动。所有写请求在退出状态下拒绝；配置、上传及连接测试在途时不退出。空默认配置初始化不延长空闲计时，旧版能力缺失时显示准确提示。
